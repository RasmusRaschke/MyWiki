# Category

``` ad-Definition
title: Definition (Category of Abelian Groups).
The [[category|category]] $\AGrp$ of abelian groups consists of abelian groups as objects and [[group##Morphisms of $\Grp$|group homomorphisms]] as objects.
```

## Objects of $\AGrp$
``` ad-Definition
title: Definition (Abelian Group).
An <u>abelian group</u> is a [[group##Objects of $\Grp$|group]] $(G, \ast)$ such that $\ast$ is commutative:
$$ \forall g,h \in G: \, g \ast h = h \ast g.$$
```
