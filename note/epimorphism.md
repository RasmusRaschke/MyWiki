```ad-Definition
title: Definition (Epimorphism).
Given a [[category|category]] $\mathtt{C}$, a morphism $f \in \mathtt{C}(a,b)$ is called <u>epimorpism</u> or <u>epic</u> if it has the following property:
For any two morphisms $g_1, g_2: b \rightrightarrows c$, $g_1f = g_2f$ implies $g_1 = g_2$.
In this case, we denote $f$ by $f: a \twoheadrightarrow b$
```

**Remark**
In the [[opposite_category|opposite category]], epimorphisms are [[monomorphism|monomorphisms]].
