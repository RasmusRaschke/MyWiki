```ad-Definition
title: Definition (Monomorphism).
Given a [[category|category]] $\mathtt{C}$ and a morphism $f \in \mathtt{C}(a,b)$, $f$ is called <u>monomorphism</u> or <u>monic</u> if it has the following property:
For any two morphisms $g_1,g_2: z \rightrightarrows a$, $fg_1 = fg_2$ implies $g_1=g_2$.
In this case, we denote $f$ by $a \rightarrowtail b$.
```

**Remark**
A monomorphism is an [[epimorphism|epimorphism]] in the [[opposite_category|opposite category]].
