# Modules

```ad-Definition
title: Definition (Simple Module).
An $R$-[[module|module]] $M$ is called <u>simple</u> if $M \neq \{0\}$ and the only submodules of $M$ are $M$ and $\{0\}$.
```

```ad-Definition
title: Definition (Semisimple Module).
An $R$-[[module|module]] $M$ is <u>semisimple</u> if it is isomorphic to a direct sum of simple modules.
```

_Examples_

1. $\{0\}$ is semisimple, but not simple, since we allow the empty direct sum $\oplus_{\emptyset}$.
2. $\mathbb{Z}$ is not simple as a module over itself since $2\mathbb{Z} \leq \mathbb{Z}$.
3. $\mathbb{Z} / p \mathbb{Z}$ is simple if $p$ is prime.
4. Any simple $\mathbb{K}$-[[vector space.md|vector space]] is [[isomorphism|isomorphic]] to $\mathbb{K}$, so all $\mathbb{K}$-[[vector space.md|vector spaces]] are semisimple.

# Rings

```ad-Definition
title: Definition (Semisimple Ring).
A [[ring|ring]] $R$ is called <u>semisimple</u> if any of the following equivalent conditions hold:
1. Every [[short exact sequence|short exact sequence]] of $R$-modules splits.
2. All right $R$-modules are semisimple.
3. All finitely generated $R$-modules are semisimple.
4. $R_R$ is semisimple.
```
